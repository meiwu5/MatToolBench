# 各软件启动状态与快捷键参考

本文档对应 GUI Agent 中每个材料科学软件的启动初始状态和关键操作，在执行任务前必须阅读对应软件章节。

---

## Jade（XRD 分析）

**启动初始状态**：程序启动时 "Read Pattern Files" 数据库对话框**已预先打开**（相当于已执行 Ctrl+R）。

> **第一步必须关闭此对话框**（点击 Close 按钮）。
> 此对话框用于参考图谱，**不是**用来打开样品数据文件的。

**打开样品文件**：关闭对话框后，使用 Ctrl+R（File → Read）。支持格式：`.raw`、`.txt`、`.mdi`。

**全谱拟合 / Rietveld**：通过 Refinement 菜单访问。

---

## Avantage（XPS 分析）

**启动初始状态**：文件 Open 对话框**已预先触发**（相当于已执行 Ctrl+O）。

- 如果启动时对话框可见：直接在对话框中输入文件路径，按 Enter。**不要**再去点 File 菜单。
- 如果启动时对话框不可见：使用 Ctrl+O 或 File → Open。

**所有文件类型**（`.VGD`、`.avg`）均通过 File → Open（Ctrl+O）打开。**不要**使用 File → Import。

**打开 .VGD 文件**：Open 对话框的文件类型过滤器可能默认不显示 .VGD 文件。若文件不可见，将文件类型下拉框改为 "Avantage Data Files (*.vgd)" 或 "所有文件 (*.*)"。

**显示模式**：从工具栏或 View 菜单访问；可切换堆叠/叠加/单独图形视图。

**峰拟合**：在 Processing 菜单下。

---

## Origin（数据分析 / 绘图）

**启动初始状态**：目标 `.opju` 文件**已打开**，Code Builder**已打开**（相当于已执行 Alt+4）。

> **不要**尝试重新打开文件或重启 Code Builder，直接进入脚本输入步骤。

**关键快捷键**：
| 快捷键 | 功能 |
|---|---|
| Alt+4 | 打开 Code Builder |
| F5 | 运行当前脚本 |
| Ctrl+N | 新建 Python 文件 |
| Ctrl+O | 打开文件对话框 |
| Ctrl+A | 全选 |

**如果 Code Builder 被意外关闭**：按 Alt+4 重新打开。

**如果 Code Builder 无文件 tab**（编辑区没有文件名标签）：按 Ctrl+N 先新建一个 Python 文件。

**代码输入方式（推荐，CRITICAL）**：
1. 点击编辑区确保焦点
2. 按 Ctrl+A 全选，按 Delete 清空
3. `computer.clipboard.copy_text("...完整脚本...")` 复制到剪贴板
4. `computer.clipboard.paste()` 粘贴到编辑器
5. **绝对不要用 `computer.keyboard.write()` 输入脚本**——它只支持 ASCII，会损坏 Unicode 字符

**粘贴后出现乱码或缩进错误**：Ctrl+A → Delete 清空，将脚本拆成 2-3 段分别粘贴。

## VESTA（晶体结构可视化）

**启动初始状态**：文件 Open 对话框**已预先触发**（相当于已执行 Ctrl+O）。

- 如果对话框可见：直接输入文件路径，按 Enter。
- 如果对话框不可见：使用 File → Open（Ctrl+O）。

**支持文件格式**：`.cif`、`.vesta`

**导出图像**：File → Export Raster Image

---

## DigitalMicrograph / DM

**启动初始状态**：文件 Open 对话框**已预先触发**（相当于已执行 Ctrl+O）。

- 如果对话框可见：直接输入文件路径，按 Enter。

**支持文件格式**：`.dm3`、`.dm4`

**左侧面板**：启动时左侧可能有 "Histogram"、"Images"、"Status" 等面板，会遮挡工作区。

> **第一步先关闭该面板**（点击 × 关闭按钮），再继续任务。

---

## Materials Studio

**CRITICAL — 启动后第一步必须最大化窗口**：

在做任何操作之前，确认 Materials Studio 窗口铺满整个屏幕。如果没有最大化（能看到桌面或窗口边框），**立即**按 Win+Up 或点击最大化按钮。

> 所有基于坐标的点击操作都假设窗口已全屏，非全屏状态下点击会偏移到错误位置，导致所有后续操作失败。

**启动初始状态**：程序刚启动，窗口已最大化。无文件打开，无对话框。

**打开文件**：File → Open（Ctrl+O），然后导航到或输入文件路径。

**如果目标文件已打开**（标题栏或 Project 面板中可见）：**不要**重新打开，直接进行下一步。

---

## 通用规则

- 始终将输出文件保存到任务目标中指定的**精确路径**
- 如果出现意外对话框，先处理（确认/取消/输入路径），再继续主任务
- 如果预触发的对话框不可见（可能已被关闭），使用对应快捷键重新触发
